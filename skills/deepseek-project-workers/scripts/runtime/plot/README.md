# Installed drawing worker

Launch in PowerShell 7 with `-JobFile <absolute job JSON>`. The installer writes local `worker-config.json`;
`-Python` and `-CliPath` override it. The companion skill's `references/setup-and-jobs.md` documents fields.

A selects approved layout values; B independently reviews real previews and renderer source.
At most three layout rounds. Fixed DS Flash MAX; no native model tools or arbitrary code execution.
Only transient failed roles are replaced (default two per role, four per job), within the original budgets.
Successful roles are preserved. Scientific/data/vision/QA failures go to Root.

Candidates remain `pending_root_review`; outputs, sessions and attempt ledger stay under `runs/`.
Install-time configuration and run logs are local and are never publication assets.
