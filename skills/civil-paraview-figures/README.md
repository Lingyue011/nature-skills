# `civil-paraview-figures` 技能

[English](README_EN.md)

独立技能：使用 ParaView 和 Matplotlib 将真实有限元网格与结果整理为土木工程论文图件。

## 适合用它做什么

- 渲染有限元位移云图，组合轴测图和平视图，并核对色标与视向。
- 保留几何尺度、节点与场数据的可追溯性。

## 典型请求

- “把已接受的有限元结果做成带等比例侧视图的 ParaView 论文图。”

## 你需要提供

- 已接受的网格、位移场、参考状态、单位、目标时刻和输出要求。

## 产出

- 可复现的图面脚本、图像、视图状态和来源及质量检查记录。

## 边界

- 不授权重新求解、校准或更改科学数据；渲染通过不等于物理验证。
- 用户指定的土木配色是项目偏好，并非普遍期刊要求；应遵守实际投稿要求。

## 相关技能

- `nature-figure`：通用科研图件与普通曲线图工作流。
